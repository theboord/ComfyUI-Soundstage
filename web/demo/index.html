Soundstage · ComfyUI App

Demo: replays real GPU renders

This is the real Soundstage App, the same code that runs inside ComfyUI, running in your browser. Block the scene in 3D, then go through ① Set → ② Frame → ③ Motion → ④ Review → ⑤ Deliver. Image and video generation needs a GPU, so Run and the render buttons replay the renders ComfyUI made for these scenes (Krea 2 frames, LTX-2.5 motion with sound).

Horse and car models: CC0 (Quaternius). three.js r170. Open source; runs inside ComfyUI with Krea 2 and LTX-2.5.
