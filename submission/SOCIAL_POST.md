```
Soundstage is a custom node pack + App-mode workflow for the Open Source Higgsfield challenge. Trailer: [VIDEO_LINK]

The idea: AI video is great at pretty shots and bad at *your* shot. So you block the scene first, in 3D clay, and the models follow it.

- **Script**: import Fountain / FDX / PDF; breakdown, scene strip, auto scene setup (location, cast, time of day)
- **Cast & Locations**: "Generate all missing" with FLUX 3 Klein; per-shot cast picker; edit any ref in Paint Studio
- **Set**: clay actors with sculpted hair, Pose in 3D down to the fingertips (IK), camera rigs (dolly, jib, Steadicam, handheld), Top plan view, mocap from any video or webcam (SAM 3D Body), Video → 3D Stage
- **Frame**: FLUX 3 Klein (or Krea 2 + stage depth) paints the first frame from the clay; Paint Studio for fill / remove / extend
- **Motion**: LTX-2.5 Layout-to-Render IC-LoRA, with sound, following the blocking; type a line and LTX's own voice lip-syncs it; film-look swatches (same animation, any look)
- **Review**: 3-way Ladder (Clay | Draft | Final), approvals with Redo, Avid-style dailies bins + lined script
- **Deliver**: NLE export to Premiere / Avid / Resolve at source spec (4K/8K/RED via proxy relink), VFX Layer Pack (mattes, depth, camera)

Everything is open weights by default and runs locally. Partner API nodes are opt-in only.

GitHub (code, workflows, model list, install): https://github.com/theboord/ComfyUI-Soundstage
Try the App UI in the browser (replays real GPU renders): https://claude.ai/artifact/GwtC3yFZtGCsTsiPGbvnAq

Feedback very welcome. #OpenSourceHiggsfield
```
